模型生成效果对比

GPT-6.1 sol 效果

雨夜便利店街角 | GPT-6.1 sol 生成的页面

  1. 3D 方案选型与完整度
    Three.js 与 OrbitControls 已打包，具备旋转、缩放、平移、阻尼和触屏控制，代码完整。无需拘泥于 three.min.js 的文件名。但当前是 HTML + 外部 JS，不是严格的单 HTML。
  2. 散件组装入场动效
    确实实现了按时间错开的 position.y 上升和 scale 放大，带三次缓出。顺序包括底座、墙体、内饰、玻璃、屋顶及街角设施，约 3.7 秒完成。扣分在于以整组出现为主，散件逐个拼装的精细程度有限，后段设施入场时建筑尚未完全到位。
  3. 三渲二与雨夜氛围
    有 1500 条雨线、积水色斑、扩散涟漪，以及冷暖配色。但主体使用 MeshStandardMaterial，没有使用卡通材质，也没有实现轮廓描边。地面粗糙度统一为 0.66，所谓反光主要由透明色斑模拟，没有实际映照建筑与招牌。
  4. 室内外透视与光影反差
    玻璃设置 transparent: true、opacity: 0.1、depthWrite: false，具备透视条件。室内有独立暖色点光源、货架商品、后排冷柜、收银台和食品陈列，室外使用冷色照明。实现扎实，但屋顶和雨棚在默认俯视角下是否遮挡过多内景，需要截图确认。
  5. 细节密度与正方形底座
    底座为 12×12，包含贩卖机、自行车、雨伞架、垃圾桶、护栏、电线杆、电线、停车线、排水沟及空调外机，内容丰富。但存在明确越界：右侧停车位横线最远到 x=7，底座边界只有 x=6。公告栏和商品也主要是简单几何体，精细程度有限。

Gemini3.8 flash 效果

雨夜便利店街角 | Gemini 3.8 flash 生成的页面

  1. 3D 方案选型与完整度
    本地 bundle.js 包含 Three.js、OrbitControls 和 TWEEN，无需外部 CDN。旋转、缩放、阻尼和视角限制均有配置，代码完整。但仍是 HTML + 外部 JS，不是严格单 HTML；真实 WebGL 运行尚未验证。
  2. 散件组装入场动效
    实现了从空中落下的 position.y 动画，以及从 0.001 恢复原尺寸的缩放，位置采用 Back.Out 回弹。检查确认四组最终均能归位。但只有地面、整栋便利店、全部街角器具、全部基础设施四组，墙体、货架、屋顶没有逐层组装，距离“散件叠加”要求有明显差距。
  3. 三渲二与雨夜氛围
    实际使用 MeshToonMaterial，配有四阶渐变和最近邻采样；道路粗糙度 0.18、积水 0.05，并有 1800 条雨线、18 个动态涟漪。扣分点：描边函数只定义、没有调用；没有环境贴图或平面反射，低粗糙度可以产生灯光高光，不能据此认定有便利店倒影。
  4. 室内外透视与光影反差
    正面和侧面都有玻璃，设置透明、opacity: 0.32、transmission: 0.85、关闭深度写入。内饰包括双面货架、冷柜、收银机、关东煮、咖啡机、香烟柜与杂志架，内容丰富。但室内点光源强度仅 2.2 和 1.2，结合 Three.js r187 的灯光衰减，存在照明不足风险；白色灯板本身不会照亮货架。
  5. 细节密度与正方形底座
    底座约 20.4×20.4，有双贩卖机、自行车、雨伞架、垃圾桶、空调、箱筐、变压器、电表、垂落电线、护栏和路口反光镜，元素较丰富，主要构件从坐标看位于底座范围内。扣分在于商品主要靠平面贴图表达，自行车结构较简略，部分设备位置不合理。

DeepSeek V4.1-Flash-1017 效果

雨夜便利店街角 | DeepSeek V4.1-Flash-1017

  1. 3D 方案选型与完整度
    已引入本地 Three.js r160 和 OrbitControls，入口包含渲染循环、窗口适配、旋转与缩放限制，代码组织完整。使用 three.module.js 是合理的模块化方案，不应仅因文件名不是 three.min.js 扣分。但项目依赖 src/ 和 lib/，不满足严格意义的单 HTML。
  2. 散件组装入场动效
    有独立的 Assembly 系统，真实修改 position.y 和 scale，包含底部生长 rise、高处落下 drop、弹性放大 pop。底座从 0 秒开始，随后路面、建筑、室内、招牌、道具、电线陆续入场，最后引入雨效。扣分在于不少对象按整组缩放，例如墙体与屋顶设备一起生长，距离逐件搭建、逐层叠放还有差距。
  3. 三渲二与雨夜氛围
    有 MeshToonMaterial、四阶明暗渐变和 EdgesGeometry 描边；雨效包含 1500 条 GPU 雨丝和 34 个循环涟漪，冷色雾与霓虹呼吸也有实现。主要不足是路面使用卡通材质，积水和倒影主要是透明加色贴片，没有低粗糙度湿地材质及真实场景反射。
  4. 室内外透视与光影反差
    橱窗设置 transparent: true、opacity: 0.05、depthWrite: false；室内有四个暖色 PointLight 和一个冷色补光，并建有货架、冰柜、收银台等内容。室外采用冷色月光，冷暖对比的技术条件充分。
  5. 细节密度与正方形底座
    主台面为 26 × 26，底座也是正方形；贩卖机、自行车、雨棚、电线杆、路灯、护栏、标线、井盖、空调等都有实现。自行车长约 1.8，店面宽约 11.7，比例没有明显失控。
